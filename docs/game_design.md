# Game Design (Stage 1 summary)
Ethan travels the world skateboarding famous locations; first stop Venice Beach, California.
Pillars: smooth arcade skating, relationships and story (later), social following, wellbeing.
Stage 1 scope is skating only: push → cruise → jump → land → grind → exit → continue.
Scoring: +10 per clean landing; grinds award duration × rail score × rail multiplier.
Falls: pothole, hard landing (>1500 px/s), or hitting a vertical face at ≥330 px/s. Ethan recovers after ~1.1 s with brief invulnerability.
